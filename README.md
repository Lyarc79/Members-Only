# Members Only

A full-stack web application for a message board built with **Node.js**, **Express**, **PostgreSQL**, and **EJS**, following the **MVC architecture**.

## Key Features

- **MVC Architecture:** Structured routes, controllers, views and database queries.
- **Authentication & Authorization**: Secure sign-up, login, and session management using Passport.js.
- **Role-Based Access Control:** Hidden metadata only to club members; message deletion reserved for admins.
